# Mumatec Main Website

Modern replacement for the WordPress Phox website at https://mumatechosting.co.za.

## Goals
- Keep the existing Mumatec logo and brand identity.
- Reuse design tokens and visual patterns from `ramanugut/MumatecManager` where suitable.
- Build a fast, accessible, responsive public marketing site without WordPress.
- Connect domain searches, hosting purchases, sign-in and customer support to the existing WHMCS system through secure server-side integrations.
- Do not expose WHMCS API credentials in the browser.

## Planned pages
Home, Web Hosting, Domains, Website Services, Support, Contact, and legal pages.

## Delivery rules
- Do not replace the live site before testing and approval.
- Confirm existing branding assets, hosting products and pricing before publishing.
- Build and test the customer journey from plan selection to checkout.
- Maintain consistent desktop and mobile information hierarchy.
- Keep MumatecManager unchanged: it is the design reference, not the public website.

## Status
Initial repository setup. Implementation and deployment are not yet complete.
